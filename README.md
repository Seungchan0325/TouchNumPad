# TouchNumPad

**TouchNumPad**는 Windows 11 랩탑의 정밀 터치패드(Precision Touchpad)를 화면상의 넘패드(Numpad)와 1:1로 매핑하여 사용할 수 있게 해주는 경량 유틸리티입니다.

---

## 주요 기능

- **터치패드 비율 1:1 일치 5×4 넘패드**
  - 노트북 터치패드의 실제 물리 종횡비(Physical Aspect Ratio)를 하드웨어에서 자동 감지하여 화면 창을 1:1 완벽하게 동일한 비율로 띄웁니다.
  - **우측 숫자 집중 배치**: `7~9`, `4~6`, `1~3`, `0(2칸)`, `.`
  - **좌측 기능/연산자 배치**: `Backspace`, `=`, `÷`, `×`, `−`, `+`, `Enter(2칸)`
  - 숫자 1, 2, 3 바로 옆에 `+`가 배치되어 덧셈 연산 동선이 극대화되어 있습니다.
- **헤더리스 초미니멀 디자인**
  - 제목 표시줄, 앱 아이콘, 설정/닫기 버튼을 완전히 제거하고 화면에 순수 넘패드 표면(Mica 재질과 둥근 모서리)만 깔끔하게 표시됩니다.
- **두 손가락 실시간 적응형 조절 (Adaptive Transform)**
  - 넘패드 모드 사용 중 터치패드에 두 손가락을 올려:
    - **크기 조절(Pinch)**: 두 손가락을 모으거나 벌려 넘패드 크기 확대/축소 (0.4배 ~ 1.0배)
    - **각도 회전(Rotate)**: 두 손가락을 비틀어 내 손목 각도에 맞게 넘패드 회전 (-45° ~ +45°)
    - **위치 이동(Pan)**: 두 손가락으로 드래그하여 터치패드 내 원하는 위치(예: 우측 집중)로 이동
  - 조작 시 화면상에 은은한 가이드라인 오버레이가 표시되며, 손을 떼면 설정이 영구 저장됩니다.
- **5번 홈 키 물리 돌기 & 키 진입 피드백 (햅틱 & 사운드)**
  - **5번 홈 키 돌기 (Distinct Bump)**: 드래그 중 기준점인 5번 키에 들어서면 묵직한 이중 펄스(Bump) 피드백으로 실제 물리 키캡의 돌기 감각을 재현합니다.
  - **일반 키 진입 (Light Tick)**: 키 경계를 넘을 때마다 가볍고 산뜻한 마이크로 틱 피드백을 제공합니다.
  - **하드웨어 자동 감지**: 정밀 햅틱 터치패드 기기에서는 물리 진동 햅틱으로, 미지원 기기에서는 초경량 마이크로 사운드로 즉시 출력됩니다 (설정에서 햅틱/사운드/볼륨 독립 제어 가능).
- **스마트 마우스 전환**
  - **영역 바깥 1회 터치 무시**: 손바닥이나 실수 스침은 완벽히 무시(Palm Rejection).
  - **영역 바깥 더블 클릭**: 넘패드 바깥 영역을 더블 클릭하면 즉시 마우스 커서가 나타나며 일반 터치패드로 전환.
  - **가장자리 드래그 탈출**: 넘패드 끝까지 크게 드래그하면 마우스 모드로 탈출.
  - **넘패드 복귀**: 마우스 모드에서 넘패드 창을 클릭하면 즉시 마우스가 숨겨지고 넘패드 모드로 복귀.
  - **창 이동**: 마우스 모드에서 넘패드 표면 아무 곳이나 잡고 드래그하면 창 위치 이동 가능.
- **빠른 열기 / 닫기**
  - **터치패드 상단 제스처**: 상단을 `좌 → 우`로 쓸어내리면 열기, `우 → 좌`로 쓸어내리면 닫기.
  - **전역 단축키**: 기본 `Shift + Alt + N` (설정에서 PowerToys 스타일 단축키 레코더로 변경 가능).
  - **입력 위치(캐럿) 자동 감지**: 텍스트 입력 중 호출 시 활성 커서/입력칸 근처에 창을 자동 배치.
- **시스템 트레이 상주**
  - 작업 표시줄 알림 영역 아이콘 우클릭으로 언제든 설정(`⚙`), 숨기기, 종료에 접근 가능.

## 사용 방법

| 동작 | 방법 |
| :--- | :--- |
| **넘패드 열기** | 터치패드 상단 `좌 → 우` 쓸어내리기 또는 `Shift + Alt + N` |
| **넘패드 닫기** | 터치패드 상단 `우 → 좌` 쓸어내리기 또는 `Shift + Alt + N` |
| **숫자 / 연산자 입력** | 넘패드 모드에서 원하는 키 위치 확인 후 탭(또는 물리 클릭) |
| **넘패드 크기 / 각도 / 위치 조절** | 터치패드에 두 손가락을 올려 핀치(크기), 회전(각도), 드래그(위치) |
| **일반 마우스로 전환** | 넘패드 영역 바깥을 더블 클릭하거나, 가장자리 끝까지 크게 드래그 |
| **다시 넘패드 모드로 복귀** | 마우스로 넘패드 창 클릭 |
| **창 위치 이동** | 마우스 모드에서 넘패드 표면 아무 곳이나 잡고 드래그 |
| **설정 열기 / 종료** | 작업 표시줄 오른쪽 시스템 트레이 아이콘 우클릭 메뉴 |

## 기술 스택

- **Framework**: .NET 10.0 (`net10.0-windows10.0.22621.0`)
- **UI**: WinUI 3 (Windows App SDK 1.6)
- **Feedback**: `Windows.Devices.Haptics` API + Win32 PCM 마이크로 오디오 합성기
- **System Interop**: Win32 Raw Input (`WM_INPUT`), HID Parser (`hid.dll`), Low-Level Hooks (`WH_MOUSE_LL`, `WH_KEYBOARD_LL`), UI Automation (`IUIAutomation`)

---

## 빌드 및 실행

```powershell
# 빌드 (Release)
dotnet build -c Release

# 실행 (Release)
dotnet run -c Release
```

설정은 `%LOCALAPPDATA%\TouchNumPad\settings.json`에 자동으로 저장됩니다.
